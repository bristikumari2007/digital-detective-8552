# task 1.1 - trace one activity using ipos

activity: typing and saving a college essay in a text editor

| stage | what happens in your example | possible hardware / component |
| --- | --- | --- |
| input | user presses keys on keyboard and moves mouse to edit text | keyboard and mouse |
| processing | processor formats characters and stores text in memory | cpu and ram |
| output | words appear on screen so user can read what is typed | monitor or laptop display |
| storage | user clicks save and document file writes to solid state drive | ssd or internal drive |

## how the activity moves from input to storage

keystrokes from keyboard enter memory as character codes
cpu processes the characters and sends image signals to screen display
when user clicks save button cpu transfers file data from ram to ssd for permanent saving

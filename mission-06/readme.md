## commands / tools used

- git status: checks working tree status
- git add: stages modified files
- git commit: saves snapshot to git history
- git branch: creates and lists branches
- git switch: switches active branch
- git merge: merges branch changes into main
- git log: views commit history

## my understanding

git records file history so you can track changes and return to earlier states
staging lets you choose specific files to bundle into a commit
branches let developers work on features without affecting main branch until work is ready

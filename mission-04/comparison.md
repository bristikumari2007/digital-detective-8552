# task 4.2 - compare compiler and interpreter

| point | compiler | interpreter |
| --- | --- | --- |
| when translation / execution happens | translates entire program into machine code before execution | translates and runs code line by line at runtime |
| typical output | standalone executable file or binary | no standalone binary executes instructions directly |
| one example | c or c++ compiler like gcc | python interpreter |
| one advantage | runs faster because program is already translated | easy to test and debug because code runs without compile step |

## explanation of differences

a compiler translates complete source code into machine instructions before the program runs
an interpreter reads and executes program instructions line by line while the program runs
compilers give fast execution speed while interpreters make testing and debugging simpler

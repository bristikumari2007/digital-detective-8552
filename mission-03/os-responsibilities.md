# task 3.4 - operating system responsibilities

| os responsibility | your explanation | example |
| --- | --- | --- |
| process management | creates schedules and terminates running programs while sharing cpu time | running browser and text editor at same time |
| memory management | allocates ram space to open programs and frees memory when closed | giving ram space to python interpreter when launched |
| device management | coordinates communication between computer and hardware peripherals | using printer driver to send print jobs to printer |
| file management | organizes files and directories on disk and manages reading and writing | creating folders and saving files on storage drive |
| user interface / shell | provides visual desktop or terminal shell for user to enter commands | terminal command line or graphical desktop window |
| security and permissions | controls access to system resources and prevents unauthorized file edits | restricting file editing using read write execute permissions |

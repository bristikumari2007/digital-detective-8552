# task 7.1 - explain network concepts

| concept | explain it in your own words | example |
| --- | --- | --- |
| lan | local area network covering a small area like home room or office | home wifi network connecting laptop phone and printer |
| man | metropolitan area network covering a town city or campus | network connecting municipal government offices across city |
| wan | wide area network covering large geographical areas or countries | the global internet |
| dns | domain name system translating website name into numeric ip address | translating example.com into ip address 93.184.215.14 |
| router | network hardware device that forwards data packets between different networks | home broadband router connecting local devices to internet |
| protocol | standard set of communication rules that devices follow to exchange data | http https tcp and ip |
| packet switching | technique of breaking data into small packets and sending them independently | web pages split into packets sent across internet and reassembled |
| client-server | network architecture where client requests service and server provides it | web browser requesting webpage from web server |

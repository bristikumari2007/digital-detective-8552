# task 7.3 - what happens when you open a website

1 user enters website domain name into web browser client
2 browser client checks cache and sends query to dns server to find ip address
3 dns server resolves domain name and returns matching server ip address to browser
4 browser client creates connection request using https protocol
5 local router forwards data packets across internet routers toward destination server
6 destination web server receives request processes it and sends webpage data back in packets
7 browser client receives packets reassembles data and displays rendered webpage to user
